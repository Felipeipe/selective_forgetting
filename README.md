# selective_forgetting
Repository of project of course EL7024: Selective Forgetting via Information Theoretic Measures


Código con métodos de estimación de información mútua que se pueden usar:

- KSG mixto: https://github.com/jannisteunissen/mutual_information

usar implementación sklearn.feature_selection.mutual_info_classif https://scikit-learn.org/stable/modules/generated/sklearn.feature_selection.mutual_info_classif.html

- MINE mixto: https://github.com/tdemin16/group-robust_machine_unlearning/blob/main/method/approaches/miu.py

Arquitectura a usar: MLP (se puede variar número de neuronas y capas).
